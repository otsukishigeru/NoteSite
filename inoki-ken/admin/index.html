新しい ID を追加する

まとめて追加する

記名式のアンケートでは、提出する方ごとに別の ID が必要です。人数が多いときは、 1行に1名ずつ「ID,SubID,メモ」の形で貼り付けて、まとめて登録できます（メモは省略可、一度に200件まで）。 表計算ソフトから貼り付けた、タブ区切りの行もそのまま使えます。 1行でも不備があると、1件も登録せずに不備のある行をお知らせします。

入力の決まり

  • ID は半角の英数字・ハイフン・アンダースコア・ピリオドで、2〜40文字。
  • SubID は 4〜60文字。日本語も使えますが、伝えやすさを考えると半角がおすすめです。
  • 同じ ID を二つ登録することはできません。
  • 記名式のアンケートに提出する方には、共有の ID ではなく、一人ずつ別の ID をお渡しください。

管理パスワードについて

このページの管理パスワードは、サイト全体で共通の環境変数 ADMIN_PASSWORD（Vercelのプロジェクト設定）です。 変更する場合はVercelのダッシュボードから行ってください。

surveys

アンケートの編集

設問の追加・削除・変更を、この画面から行えます

編集のしかた

編集したいアンケートを選び、内容を書き換えたうえで「この定義を保存する」を押してください。 押すまでは、変更はこの画面の中にとどまっており、公開されているサイトには反映されません。 すでにお寄せいただいた回答は、設問を書き換えても消えません。 設問の id を変えると別の設問として扱われますので、 文言だけを直したい場合は id を変えないでください。

　

submissions

提出物（記名式アンケート）

記名式のアンケートに寄せられた提出を、ID ごとに確認・書き出します

「アンケートの編集」で「記名式にする」を選んだアンケートについて、提出を ID ごとにまとめて表示します。 ID を押すと、その ID の提出が新しい順に開きます。同じ ID から何度か提出された場合はすべて残り、 いちばん新しいものに［最新］の印が付きます。記名式に切り替える前の提出は、ID が記録されていないため 「ID不明」にまとめています。

ZIP のフォルダ構成

書き出した ZIP を展開すると、いちばん上のフォルダの中に「一覧.csv」と、ID ごとのフォルダができます。 各 ID のフォルダには、提出1件につき1つのテキストファイル（UTF-8）が入ります。 ファイル名は「アンケートid_提出日時.txt」で、本文のほか、プロフィールと各設問への回答も含みます。 「すべての記名式アンケート」を選んで書き出すと、同じ方の事前アンケート・本体・事後アンケートが 一つの ID フォルダにそろいます。

data

回答データ

集まった回答の書き出しと消去を行います

回答は匿名で保存されています（記名式のアンケートを除きます）。CSVとして書き出せば、Googleスプレッドシートや Dropbox に取り込んで、 独自の分析を行うことができます。書き出しても、もとの回答は残ります。 記名式のアンケートのCSVには「ID」の列が加わります。ID ごとに確認したいときは「提出物」タブをお使いください。

自由記述をお読みになるには

自由記述にお書きいただいた文章は、回答者向けの集計ページには出さないようにしました。 全文をお読みになるときは、この画面の「CSVを書き出す」をお使いください。 書き出したCSVには、これまでどおり記述の全文が含まれます。 なお「集計を見る」で開くページは回答者向けのものですので、記述の件数しか表示されません。

消去について

「回答を消去」を押すと、そのアンケートに寄せられた回答がすべて失われます。取り消しはできません。 試験的に入力したものを片づけるとき以外は、先にCSVを書き出しておくことをおすすめします。
