入力の決まり

  • ID は半角の英数字・ハイフン・アンダースコア・ピリオドで、2〜40文字。
  • SubID は 4〜60文字。日本語も使えますが、伝えやすさを考えると半角がおすすめです。
  • 同じ ID を二つ登録することはできません。

管理パスワードについて

このページの管理パスワードは、サイト全体で共通の環境変数 ADMIN_PASSWORD（Vercelのプロジェクト設定）です。 変更する場合はVercelのダッシュボードから行ってください。

surveys

アンケートの編集

設問の追加・削除・変更を、この画面から行えます

編集のしかた

編集したいアンケートを選び、内容を書き換えたうえで「この定義を保存する」を押してください。 押すまでは、変更はこの画面の中にとどまっており、公開されているサイトには反映されません。 すでにお寄せいただいた回答は、設問を書き換えても消えません。 設問の id を変えると別の設問として扱われますので、 文言だけを直したい場合は id を変えないでください。

　

data

回答データ

集まった回答の書き出しと消去を行います

回答は匿名で保存されています。CSVとして書き出せば、Googleスプレッドシートや Dropbox に取り込んで、 独自の分析を行うことができます。書き出しても、もとの回答は残ります。

アンケート 状態 回答数 操作

消去について

「回答を消去」を押すと、そのアンケートに寄せられた回答がすべて失われます。取り消しはできません。 試験的に入力したものを片づけるとき以外は、先にCSVを書き出しておくことをおすすめします。

definition

定義（JSON）

画面の編集で足りないときは、ここで直接書き換えられます

お使いになる前に

ここでの書き換えは、アンケート全体の構造にそのまま反映されます。 保存の前に構造の検査は行いますが、意味の正しさまでは確かめられません。 書き換える前に、いちど「いまの定義を書き出す」で控えを取っておくことをおすすめします。
