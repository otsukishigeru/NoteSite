入力の決まり

  • ID は半角の英数字・ハイフン・アンダースコア・ピリオドで、2〜40文字。
  • SubID は 4〜60文字。日本語も使えますが、伝えやすさを考えると半角がおすすめです。
  • 同じ ID を二つ登録することはできません。

管理パスワードについて

このページの管理パスワードは、サイト全体で共通の環境変数 ADMIN_PASSWORD（Vercelのプロジェクト設定）です。 変更する場合はVercelのダッシュボードから行ってください。
