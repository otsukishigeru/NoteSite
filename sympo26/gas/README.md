# Sympo26Reg — 参加申込みデータの集計設定

Symposium2026 の参加申込みフォーム（`/sympo26/` の「参加申込」）から送信された内容を、
Google スプレッドシート「**Sympo26Reg**」に集計するための設定手順です。

申込データは Vercel 側の Upstash Redis（キー `sympo26:registrations`）にも常に保存されるため、
スプレッドシートの設定前に届いた申込みが失われることはありません。

---

## 1. スプレッドシートを作る

1. Google ドライブで新しいスプレッドシートを作り、名前を **`Sympo26Reg`** にします。
2. 見出し行はスクリプトが自動で作るので、空のままで構いません。

## 2. Apps Script を貼り付ける

1. スプレッドシートのメニューから **拡張機能 → Apps Script** を開きます。
2. `コード.gs` の中身をすべて消し、このフォルダの **`Sympo26Reg.gs`** の内容を貼り付けます。
3. 合言葉を使う場合は、先頭の `var SHARED_TOKEN = '';` に任意の文字列を入れます
   （例：`var SHARED_TOKEN = 'sympo26-abc123';`）。空のままでも動きます。
4. 保存します。

## 3. ウェブアプリとしてデプロイする

1. 右上の **デプロイ → 新しいデプロイ** を選びます。
2. 種類は **ウェブアプリ** を選択します。
3. 「次のユーザーとして実行」＝ **自分**、「アクセスできるユーザー」＝ **全員** に設定します。
4. デプロイすると **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）が表示されるので控えます。
5. 初回は Google の承認画面が出るので、承認します。

> スクリプトを修正したときは、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ**
> の順で更新します。「新しいデプロイ」を選ぶと URL が変わってしまうので注意してください。

## 4. Vercel に環境変数を登録する

Vercel のプロジェクト設定 → Settings → Environment Variables に、以下を登録します。

| 変数名 | 値 | 必須 |
|---|---|---|
| `SYMPO26_SHEET_WEBHOOK_URL` | 手順3で控えたウェブアプリの URL | スプレッドシート集計に必要 |
| `SYMPO26_SHEET_TOKEN` | 手順2で決めた合言葉（設定した場合のみ） | 任意 |
| `RESEND_API_KEY` | Resend の API キー | メール送信に必要 |
| `SYMPO26_MAIL_FROM` | 送信元アドレス（例：`Symposium2026 <sympo26@（認証済みドメイン）>`） | 申込者への御礼メールに必要 |

登録後、`vercel --prod --yes` で再デプロイすると反映されます。

### `SYMPO26_MAIL_FROM` についての注意

Resend の初期状態の送信元 `onboarding@resend.dev` は、**Resend アカウント所有者のアドレス宛にしか送信できません**。
そのため、この状態では事務局宛（`otsuki.s.1corp@gmail.com`）のメールは届きますが、
申込者宛の御礼メールは送信に失敗します。

申込者へ御礼メールを届けるには、Resend でドメイン（例：`chidouka-lab.com`）を認証し、
そのドメインのアドレスを `SYMPO26_MAIL_FROM` に設定してください。

## 5. 動作確認

`/sympo26/` の「参加申込」からテスト送信し、次の3点を確認します。

- スプレッドシート「Sympo26Reg」の「申込一覧」シートに行が追加されること
- `otsuki.s.1corp@gmail.com` に「Sympo26Reg：参加申込」が届くこと
- 申込者アドレスに「Re:Sympo26Reg：参加申込」が届くこと（参加料が明記されていること）
