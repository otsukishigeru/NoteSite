# Sympo26Reg — 参加申込みデータの集計設定

Symposium2026 の参加申込みフォーム（`/sympo26/` の「参加申込」）から送信された内容を、
Google スプレッドシート「**Sympo26Reg**」に集計するための設定手順です。

申込データは Vercel 側の Upstash Redis（キー `sympo26:registrations`）にも常に保存されるため、
スプレッドシートの設定前に届いた申込みが失われることはありません。

---

## 1. スプレッドシートを作る

1. **`otsuki.s.1corp@gmail.com` で Google にログインします。**
   スプレッドシートも Apps Script も、このアカウントの所有として作成します
   （申込みメールの送信元と同じアカウントに揃えるためです）。
2. Google ドライブで新しいスプレッドシートを作り、名前を **`Sympo26Reg`** にします。
3. 見出し行はスクリプトが自動で作るので、空のままで構いません。

## 2. Apps Script を貼り付ける

1. スプレッドシートのメニューから **拡張機能 → Apps Script** を開きます。
2. `コード.gs` の中身をすべて消し、このフォルダの **`Sympo26Reg.gs`** の内容を貼り付けます。
3. 先頭の `var SHARED_TOKEN = '';` に、事務局で決めた合言葉を入れます
   （`var SHARED_TOKEN = '（合言葉）';` の形）。合言葉が一致しないリクエストは記録せずに拒否します。
4. 保存します。

> **合言葉はリポジトリに書かないでください。**
> このリポジトリは公開されているため、`Sympo26Reg.gs` の `SHARED_TOKEN` は空欄のままコミットしています。
> 実際の値は、この Apps Script エディタと、手順4の Vercel 環境変数 `SYMPO26_SHEET_TOKEN` の
> 2か所にだけ入力してください。

## 3. ウェブアプリとしてデプロイする

1. 右上の **デプロイ → 新しいデプロイ** を選びます。
2. 種類は **ウェブアプリ** を選択します。
3. 「次のユーザーとして実行」＝ **自分（otsuki.s.1corp@gmail.com）**、
   「アクセスできるユーザー」＝ **全員** に設定します。
4. デプロイすると **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）が表示されるので控えます。
5. 初回は Google の承認画面が出るので、承認します。

> スクリプトを修正したときは、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ**
> の順で更新します。「新しいデプロイ」を選ぶと URL が変わってしまうので注意してください。

## 4. Vercel に環境変数を登録する

Vercel のプロジェクト設定 → Settings → Environment Variables に、以下を登録します。

| 変数名 | 値 | 必須 |
|---|---|---|
| `SYMPO26_SHEET_WEBHOOK_URL` | 手順3で控えたウェブアプリの URL | スプレッドシート集計に必要 |
| `SYMPO26_SHEET_TOKEN` | 手順2で `SHARED_TOKEN` に入れた合言葉と同じ値 | 合言葉を使う場合は必須 |
| `GMAIL_USER` | `otsuki.s.1corp@gmail.com` | メール送信に必要 |
| `GMAIL_APP_PASSWORD` | Google の「アプリ パスワード」（16桁） | メール送信に必要 |

登録後、`vercel --prod --yes` で再デプロイすると反映されます。

## 5. メールの送信元について

申込みメールは **`otsuki.s.1corp@gmail.com` から** 送信します。差出人の表示名は次のとおりです。

| 宛先 | 件名 | 差出人の表示名 |
|---|---|---|
| 事務局（`otsuki.s.1corp@gmail.com`） | `Sympo26Reg：参加申込` | Symposium2026 参加申込フォーム |
| 申込者 | `Re:Sympo26Reg：参加申込` | Symposium2026 プログラム委員長 大槻 繁 |

申込者宛の御礼メールは、プログラム委員長 大槻 繁 名義の文面で、参加料（¥5,000 または 無料）を明記します。
申込者が返信すると `otsuki.s.1corp@gmail.com` に届きます。

### アプリ パスワードの作り方

Gmail は通常のログインパスワードでの外部送信を許可していないため、専用の「アプリ パスワード」を使います。

1. `otsuki.s.1corp@gmail.com` で Google アカウントにログインします。
2. **セキュリティ → 2段階認証プロセス** を有効にします（有効でないとアプリ パスワードを作れません）。
3. **セキュリティ → アプリ パスワード** で新しいパスワードを作成します（名前は「Sympo26Reg」など）。
4. 表示された16桁の文字列を、Vercel の環境変数 `GMAIL_APP_PASSWORD` に **Vercel の画面で直接** 入力します。
   この値はメールアカウントの鍵ですので、リポジトリやチャットには貼らないでください。

> **Resend について**
> `GMAIL_APP_PASSWORD` が未設定のときだけ、既存の Resend（`RESEND_API_KEY` / `SYMPO26_MAIL_FROM`）に
> 自動で切り替わります。Gmail 送信を使う場合、Resend のドメイン認証は不要です。

## 6. 動作確認

`/sympo26/` の「参加申込」からテスト送信し、次の3点を確認します。

- スプレッドシート「Sympo26Reg」の「申込一覧」シートに行が追加されること
- `otsuki.s.1corp@gmail.com` に「Sympo26Reg：参加申込」が届くこと
- 申込者アドレスに「Re:Sympo26Reg：参加申込」が届くこと（参加料が明記されていること）
